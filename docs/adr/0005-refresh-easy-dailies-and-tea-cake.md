# 大侠之路先刷新成好做条目，并做免费喝茶饼

大侠之路不接受面板上随机刷出的任何条目。先认出每一条是什么，不是好做条目就刷新，换成好做条目再做。刷新不消耗货币，也不设次数上限。刷新按钮不在了，就跳过这一条。好做条目以实机卡片为准：在线一分钟、浏览一次江湖笔记、浏览设计站、领取茶饼或品茗、查看沙盘界面、给侠士名片点赞，以及仍可能出现的奇遇手册、召唤宠物。卡片上有「已完成」就跳过。许愿树许愿、名望事件、查看好友装备、名剑大会点这张卡片自己的「刷新」，不点最右边那一个。查看沙盘界面打不开就刷新这一张。每日领到 100 后点宝箱，再点「每周」领宝箱。浏览设计站要进入设计站，点返回，再关掉外观商城。没有阵营的角色点开战争沙盘却不能查看时，把这一条刷新掉，不算完成。家园许愿的免费次数用完，或召唤宠物时没有宠物，同样刷新掉，不花钱。

领邮件时，先点右上角「菜单」，再点「邮件」。亮的「全部领取」才点。灰色表示没有可领邮件，不点。关掉邮箱后，用右上角的关闭或 Esc 回到主界面才算完成。没有这个按钮时才逐封领取。每项任务单独勾选，没勾的不执行。勾上的按这个顺序：领邮件，大侠之路，再喝茶饼。每一项开始前仍先关已知弹窗。

喝茶饼有两个选项，默认都勾上：领取当天免费茶饼、喝掉身上剩余的免费茶饼。从主界面菜单进侠影。领取只认「点击领取」，已经是「今日已领」就跳过。喝的时候先把筛选重置，只留「喝茶结交」，再寻访列表最右边的那位，点亮着的「开始翻阅」，按钮变灰就停。不花金币，不点单独的「前往」，也不把翻阅点到一百二十次。它不是茶馆日常。茶馆小童、家园管家和秘境仍不在这一版。

公开攻略里的好做名单写于苍生铸世之前。名单以实机面板为准，对不上就改名单，不把旧句子写死。
