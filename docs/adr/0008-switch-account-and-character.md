# 切换账号和角色只点画面上已有的名字

切换账号、切换角色是两项任务，默认不勾，排在日常前面。切换账号点菜单里的「切换账号」，再点客户端账号列表上已经显示的名字，停在角色选择。切换角色点填写的角色名，再点「进入游戏」，直到回到主界面。一次运行只切到这一对名字，然后做后面勾上的日常。

切换任务不读取密码、不输入密码、不填写登录验证。看到密码、登录验证、安全验证或滑块就截图并停掉当前项。选服页也不点。多名角色各自把日常重复做完仍不做，因为那是队列，不是这一次切换。
