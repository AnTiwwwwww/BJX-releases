# 任务列表可以加长，设置放在任务里面

操作界面按 MAA 的一键长草来：左边是任务勾选，一项一项增加；点进某项才看到它自己的选项。选项可以是勾选、下拉或数字，只在这项被勾上时生效。新的日常是新任务，不把行为塞进已经有的任务里。

第一版先做三项，默认都勾上。领取邮件没有选项：先点右上角「菜单」，再点「邮件」。亮的「全部领取」才点。灰色表示没有可领邮件，不点。关掉邮箱后，用右上角的关闭或 Esc 回到主界面才算完成。没有这个按钮时才逐封领取。大侠之路里面好做条目各自一个勾选，默认都勾上。实机上会做在线一分钟、江湖笔记、浏览设计站、领取茶饼或品茗、查看沙盘界面、给侠士名片点赞。卡片上有「已完成」就跳过。许愿树许愿点它自己的「刷新」。没勾的种类刷新掉。喝茶饼两个选项，默认都勾上：领取当天免费茶饼、喝掉身上剩余的免费茶饼。进侠影做，不花金币。

关已知弹窗仍不是任务。只要有任务在跑，每一项开始前都会先关。没勾的任务不执行。已经勾上的，按领邮件、大侠之路、喝茶饼的顺序跑。以后的日常按同样的格式加新任务。
