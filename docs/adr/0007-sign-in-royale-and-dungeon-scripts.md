# 签到和单人吃鸡是勾选，单人副本才导入脚本

签到是一项任务，默认不勾。点主界面上方「花萼楼」。每日签到页点中间的签筒，只点一次。左侧红点在「每日签到」下面的，点开后如果有亮的「签到领取」就点，灰色不点。出现「点击空白区域关闭」时，点「签到领取」按钮所在的位置把弹窗关掉，不点奖励图标。不点「补签」，也不点花萼楼里的其他按钮。然后用右上角的关闭或 Esc 回到主界面。

单人吃鸡刷币也是一项任务，默认不勾。主界面按 Ctrl+L 打开绝境战场。这一页默认停在五人模式，五人页底部同样有「个人匹配」，所以先点左侧「单人模式」，看到「龙门绝境」再点「个人匹配」。再次打开时如果面板已经停在单人页，就直接点「个人匹配」，不再要求左边一定有「五人模式」。打开失败、点不到单人页或三分钟后「个人匹配」还在，都先重开再试，整场累计多次仍失败才截图跳过。主界面上没打开面板时不按 Esc。可能出现匹配成功的确认页，勾选「3秒后自动进入」时等待游戏自动进入。点下去后面板还在，按钮变成「取消匹配」，上方出现「已匹配 … 预计排队 …」。这是排队，不是进场，也不算打完。不点「取消匹配」，也不按 Esc。这两个字连续三次都看不到后，继续等待局内剩余人数，避免把准备和加载当作已经开打。提交匹配后就进入本局等待，正常识别和异常分支都不能返回匹配入口。进局后大约每 10 秒按一次数字键 1，不按 2、3、4。进局满十分钟按一次 Shift+C，先按下左 Shift 再按 C 再松开，这一局不重复，排队时不按。不寻路、不捡物资、不躲圈，每次按 1 之前先看结算。右下角「下一步」「传出战场」或「退出战场」表示已看到本局退出页。只有先看到退出页、等待 2 分钟加载并确认回到主城，才允许排下一把。没看到退出页时，主城文字、主界面按钮、黑屏和陌生画面都不能证明本局结束；正常准备、局内画面等待和退出后加载持续等待，不按整次运行累计次数停止；实际操作或资源出错时截图停止，始终不重开匹配页。MXU 的停止键以设置页为准，本机是 F11。结束后游戏自己回到主城。下午默认一直打。默认打到代币获取上限：回到沧海集后重新打开绝境战场，只看底部「本周还可获得飞沙令」右边的数字，不看上面的卡片。每次点个人匹配之前把它记到 debug/royale-weekly-left.txt，并按本地邮件配置把这一条发出去。这个数字是 0 就关掉并结束，大于 0 再排一局。也可以改成只打 1 局、2 局或 3 局。进了战场之后不寻路、不捡物资、不躲圈，飞沙令按名次由游戏自己结算。死亡如果发生在进场之前，仍按重跑上限从这项开头再来。进场之后的阵亡是这一局的结果，不按死亡重跑。

导入的脚本只描述单人副本。一份脚本是 `scripts/` 里的一个目录，里面有 `pack.json` 和 `pipeline/`。以 `_` 开头的目录不导入。`tools/sync-scripts.ps1` 把任务收进 `scripts/imported.json`，并把流水线复制到 `resource/pipeline/scripts/`。节点名由脚本自己加前缀。模板里的「待校准」保持不点击，换上实机文字后再改成点击。

单人副本进门之后仍点游戏自己的前往和武学助手，不自建路线，也不排列技能。
