# BJX 0.4.1-beta.1

首次公开内测版本，当前只建议测试「单人吃鸡刷币」和「定时开始」。吃鸡前请手动切换至旗舰心法，关闭遮挡主界面的新手引导，保持窗口客户区 1920×1080、界面缩放 100%。其余任务均标注未完成。

- 修复新号在主城不动作：顶部文字识别保留原区域，并增加不含按钮图标的文字区域，兼容浅色背景；退出后的回城确认也使用同样判断。
- 保持退出确认规则：没有看到本局退出页，不能重新打开匹配流程。
- 飞沙令剩余确认为零后结束；默认截止时间为任务启动日期的次日凌晨 01:30。
- 新增可重复的 Windows 打包、校验和发布流程，提供程序整包与干净源码包。
- 增加 PowerShell 环境检查：只有系统 5.1 或缺少 7 时，弹出安装命令和微软说明页入口，阻止任务启动；已装 7 正常继续，支持标准安装目录。

下载 `BJX-win-x86_64-v0.4.1-beta.1.zip` 完整解压后运行 `mxu.exe`。需要 Windows x64、PowerShell 7 和 WebView2。`BJX-source-*.zip` 供开发者构建使用。

升级前停止任务并退出 BJX。推荐解压到新目录，再从旧目录复制自己的 `config/` 和 `accounts.csv`；保留旧目录，确认新版可运行后再自行整理。下载包不包含用户账号、通知配置、运行日志或游戏截图。

验证包括本机 26 个单画面与 4 个连续画面回放、原始故障画面回放，以及独立路径构建、包完整性、配置保留和 7 个 PowerShell 环境用例。公开 CI 没有游戏截图，不运行 OCR 回放，不将其当作在线通过。安装提示的分支与文字已检查，实际弹窗未进行界面验收。

Mirror酱尚未接入；当前 0.x 内测版本仍需手动下载，软件内自动更新没有启用。完整跨次日挂机和多账号实机表现继续收集反馈。
