# BJX 0.4.2-beta.1

- 增加纯 GitHub 联网更新，设置中可检查新版、查看更新说明、选择稳定或内测频道；无需 MirrorChyan RID/CDK，继续使用 0.x 内测版本号。
- 下载和安装前均校验 SHA-256；任务运行或定时等待时禁止安装，安装期间禁止启动新任务。
- 整包更新保留本机账号和配置。发布包使用定制 MXU 2.8.0-bjx.1，并附完整对应源码、补丁、构建方法与许可。
- 同步任务路线图和更新说明。

旧版需手动换用一次本版整包，后续才可使用内置更新。首次换包请先停止任务并关闭 BJX，解压到新目录，复制自己的 `config/`、`accounts.csv` 和本地通知配置；使用旧配置时检查更新频道是否为「内测」。全新配置默认内测。下载完成且全部任务停止后，程序会安装并重启。

当前只建议测试单人吃鸡和定时开始，吃鸡前手动切换至旗舰心法、关闭遮挡主界面的新手引导。新号主城备用识别只通过故障画面回放，实机修复尚未确认；本版未宣称解决这一问题。其余任务仍标注未完成。
