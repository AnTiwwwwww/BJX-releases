# 路线

苍生铸世刚改过日常，旧的 130 级清单不照搬。顺序按画面是否稳定来排。

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| 0 | 绑定窗口，流水线能加载 | 「探测游戏窗口」在 MXU 里跑通。本仓库现在停在这里 |
| 1 | 领取邮件、大侠之路、喝茶饼、签到、单人吃鸡刷币，都可勾选，设置在任务里面 | 邮件和签到无选项；大侠之路六种勾选；喝茶饼两个勾选；吃鸡默认打到代币上限，也可改成 1 到 3 局。吃鸡进场后不寻路 |
| 2 | 茶馆、家园管家，以及带「前往」的名望委托 | 当天出现哪句对白，就走哪条子图 |
| 3 | 单人副本由 `scripts/` 导入，各自进门、结算、领奖 | 技能循环仍交给游戏自己的单人流程。同步脚本后任务出现在列表末尾 |
| 4 | 多名角色排队重复日常、定时、失败截图 | 一个角色失败不影响下一个。单次切换账号和角色已经是勾选 |
| 5 | 没有「前往」的野外步骤才做小地图补位 | 公共任务、阵营抢活、奇遇、开荒剧情不进日常 |

采集改回探索之后，生活技能不进第一版。
