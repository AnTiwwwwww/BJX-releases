# 朋友内测说明

从 [Releases](https://github.com/AnTiwwwwww/BJX-releases/releases) 下载 `BJX-win-x86_64-v0.4.1-beta.1.zip` 整包发给朋友。它包含界面程序、MaaFramework 运行库、中文 OCR 模型、已编译的 BJX 辅助程序、源码、说明和第三方许可。无需朋友编译，也不要只发送 `mxu.exe`。`BJX-source-*.zip` 是供开发者使用的源码包。

## 第一次运行

1. 使用 Windows x64，把压缩包**完整解压**到有写权限的文件夹，不要在压缩包里直接运行。
2. 安装 [PowerShell 7](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows)，安装后重新打开 BJX。Windows 自带的 PowerShell 5.1 不能代替它，但可以与 7 并存。缺少 7 时，BJX 会弹出安装指引并阻止任务启动；已装 7 不会重复提醒。MXU 界面需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，无法打开界面时先检查是否已安装。
3. 自己登录剑网3无界，**手动切换至旗舰心法，并关闭遮挡主界面的新手引导**。使用窗口模式，客户区 1920×1080，界面缩放 100%。
4. 启动根目录的 `mxu.exe`，选中已登录的无界窗口，只勾选「单人吃鸡刷币」。首次建议将局数设为 1，完整观察匹配、进局、结算和返回主城。
5. 需要定时开跑时，勾选「定时开始」，拖到任务列表最前面，设置时间后点开始。电脑保持唤醒，游戏和 BJX 保持打开。
6. 吃鸡的「运行到几点」默认为**任务启动日期的次日凌晨 01:30**。例如 11 月 10 日启动，到 11 月 11 日 01:30 截止；即使 11 月 10 日凌晨 00:30 启动，也取 11 月 11 日。额度确认归零或所选局数跑完会提前结束。

除吃鸡和定时开始外，其余 9 项主任务及单人副本模板均标注「未完成」，当前内测不勾选，包括「运行结束后操作」。所有主任务在新配置中默认不勾选；已有配置保留用户原先的勾选状态。标注未完成的任务没有被删除。

停止快捷键以 MXU 设置页为准，也可点击停止按钮。网易 UU 远程若无法移出画面，在操控端按 `Ctrl+Alt+Enter` 退出游戏鼠标模式。吃鸡运行会使用真实键鼠，测试时保持游戏在前台。

## 更新与保留配置

当前 0.x 内测版本通过 Releases 手动更新，尚未接入 Mirror酱。先停止任务并退出 BJX，将新包解压到新目录，再复制旧目录中的 `config/` 和 `accounts.csv` 到新目录。首次打开核对任务选项与选中窗口，确认后再运行；旧目录保留供回退使用。

新包不含 `config/` 或 `accounts.csv`。发布验证使用虚构资料检查 MXU 2.8.0 整包替换规则会保留这些顶层项目，并检查其自动安装条件会等待所有任务停止。该检查不是软件内联网更新验收；接入更新服务后仍需测试下载、安装与重启全过程。

## 反馈问题

记录压缩包文件名、问题发生的本机时间、心法、任务选项、最后停在哪个页面，以及是否由定时开始触发。可在自己的电脑执行 `pwsh -NoProfile -File ./tools/export-log.ps1`，将生成的 `export/` 日志包发回；截图和日志可能显示角色资料，发送前自行检查。

内测 ZIP 不携带打包者的账号密码、通知配置、日志、游戏截图或个人 Git 历史。通知配置缺失时不会发送消息，不影响正常任务。包内只保留空白账号表模板，朋友不需要向开发者提供密码。

## 在开发机重新打包

先按 [安装说明](installation.md) 下载 `docs/dependencies.json` 固定的 5 个依赖文件到 `deps/`，然后运行：

```powershell
pwsh -NoLogo -NoProfile -File ./tools/export-beta.ps1
```

打包时逐个校验依赖 SHA-256，使用源码导出允许清单排除本机资料，重新编译两个自有辅助程序，并将当前路线图一起收录。输出 ZIP、逐文件校验清单和 ZIP 的 SHA-256 文件。运行库来自固定版本的上游原包；许可、原始说明和对应源码地址保存在 `third-party/`，BJX 的 MIT 许可不覆盖这些第三方组件。

打包检查不代替朋友电脑上的实机验收。完整一局、次日截止、长时间运行及不同心法/界面布局都需要分别记录结果。
