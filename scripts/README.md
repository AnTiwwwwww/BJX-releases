# 单人副本脚本

一个文件夹是一份脚本，只描述一个单人副本。签到和单人吃鸡刷币写在主任务里，不放这里。

以 `_` 开头的目录不会导入。`_template` 是标注「未完成」的空模板，里面的「待校准」不会点击。当前内测仅测试吃鸡和定时开始，单人副本暂不在范围内。

## 导入

1. 复制 `scripts/_template`，目录名改成这份副本的名字。
2. 改 `pack.json` 里的任务名、入口和说明。任务名要和流水线入口节点同名，并且不要和已有任务重名。
3. 节点名带上这份脚本自己的前缀。流水线里所有脚本共用一套节点名。
4. 在仓库根目录执行 `pwsh -File tools/sync-scripts.ps1`。
5. 重启 MXU。新任务出现在列表末尾，默认不勾选。

`pack.json` 里可以写这项任务自己的 `option`。图片放在该目录的 `image/` 下，同步时会复制到 `resource/image/scripts/<目录名>/`。

换上实机文字之前，动作保持 `DoNothing`。
