# BJX

剑网3无界的日常长草资源包。画面识别加模拟键鼠，任务用 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 的流水线描述。

公开仓库：<https://github.com/AnTiwwwwww/BJX-releases> · [下载内测整包](https://github.com/AnTiwwwwww/BJX-releases/releases)

当前版本 `0.4.1-beta.1`，处于内测阶段。当前仅建议测试「单人吃鸡刷币」和「定时开始」，**吃鸡运行前请手动切换至旗舰心法，并关闭遮挡主界面的新手引导**。其余任务的名称与说明均标注「未完成」，新配置默认不勾选；已有配置会保留勾选状态，请手动取消未完成任务。给朋友的文件与使用步骤见 [内测说明](docs/beta-testing.md)。当前通过 Releases 手动下载更新，Mirror酱尚未接入，软件内自动更新未启用。

## 这一版做什么

- 切换账号（未完成）：默认不勾。点客户端已经显示的账号名，停在角色选择。不填写密码。出现选服页就截图并停掉。
- 切换角色（未完成）：默认不勾。点填写的角色名，再进入世界。已经在选人界面就直接点名字。
- 账号资料：在本机 `accounts.csv` 中维护账号、密码、区服和角色名称，一行一个角色，为后续换号登录准备。用法见下方「本地账号表」。
- 领取邮件（未完成）：先点右上角「菜单」，再点「邮件」。亮的「全部领取」才点。灰色表示没有可领邮件，不点。领完后回到主界面。
- 大侠之路（未完成）：好做条目各自可勾选，默认都开。卡片上有「已完成」就跳过。浏览设计站会进入设计站再退回，查看沙盘界面打得开才算完成。许愿树、名望、好友装备这些点这张卡片自己的「刷新」。每日领到 100 后点开宝箱，再点「每周」领宝箱。
- 喝茶饼（未完成）：两个勾选，默认都开。从菜单进侠影，点「点击领取」领当天的茶饼；已经是「今日已领」就跳过。喝的时候只筛「喝茶结交」，滑到最右边的侠客，点「前往寻访」，亮的「开始翻阅」才点，变灰就停。不花金币，不点单独的「前往」。
- 签到（未完成）：默认不勾。点主界面上方「花萼楼」。每日签到点中间的签筒。左侧带红点的活动页上，亮的「签到领取」才点。奖励弹窗点「签到领取」那个位置关掉。不点「补签」。
- 任务开始前会先还原并激活无界，让截图引擎解除透明的伪最小化状态，再量客户区。前台窗口为 1920×1080 就直接继续。还最小化、激活失败或尺寸不对时弹出提醒，改好之前不往下点。界面缩放保持 100%。
- 定时开始（MXU）：从添加任务中加入「定时开始」，放在列表最前面。勾选它，设置时间，再点开始，先等待到点后执行后面勾选的任务。默认不勾选，默认时间 14:00，使用本机时间；时间已过会顺延到明天。保持 BJX、已登录的游戏和电脑唤醒。等待中点停止或按本机停止快捷键 F11 可以取消。每次运行只等待一次，吃鸡循环排下一局时继续运行。不需要定时时取消勾选。
- 运行结束后操作（未完成，MXU）。从添加任务中加入这项，勾选并放在列表最后，选择关闭 BJX、关闭无界窗口或关机。默认不勾选，默认选项为不操作。MXU 本机 Web 服务确认前面的任务都成功结束后才执行。关闭无界使用正常关闭请求，关机使用 Windows 正常关机。
- 导出日志（未完成）：默认不勾。把当前日志和报错截图复制到 export 目录并打开文件夹。关键判断另外写在 `debug/bjx.log`，例如分辨率、有没有打开绝境、飞沙令剩余、Shift+C 和任务结果。
- 单人吃鸡刷币：默认不勾，运行前请手动切换至旗舰心法。Ctrl+L 打开绝境战场，先点「单人模式」，看到「龙门绝境」后记下底部还剩的飞沙令，再点「个人匹配」。出现「取消匹配」或「预计排队」就是还在排队，不点取消。这两个字连续三次都看不到后，还要看到右上角剩余人数才确认进局。局内大约每 10 秒按一次数字键 1，不按 2、3、4。进局满十分钟后，只在确认局内时按一次 Shift+C；停止任务、排队、结算或回到主城时不按。提交匹配后只等待本局；看到右下角「下一步」「传出战场」或「退出战场」，等 2 分钟加载并确认返回主城后，才允许排下一把。未见退出页时不重开匹配页面。底部数字归 0 就停。默认打到代币上限，也可改成 1 到 3 局。「运行到几点」默认是本机时间、吃鸡任务启动日期的次日凌晨 01:30；即使凌晨 01:30 前启动也取次日。自定义时间同样按次日计算，同一任务跨午夜或排下一局时不顺延。到点结束吃鸡，额度归零或打满所选局数可提前结束。不寻路、不捡物资、不躲圈。命令行窗口按 F10 停止。
- 单人副本（未完成）：把一份脚本放进 `scripts/`，执行 `pwsh -File tools/sync-scripts.ps1`，重启 MXU 后出现在列表末尾。格式见 `scripts/README.md`。
- 每一项开始前会尝试关掉已知弹窗。关闭词还没采集，这一步目前会直接跳过。
- 离开邮箱、花萼楼、侠影或大侠之路时，用右上角的关闭或 Esc 回到主界面。上方重新看到「花萼楼」「行记」「外观」这一排才算回到。一项失败时也先回到这一页，再开始下一项。几次仍回不到，就停掉这一次运行。
- 看到「回城复活」会点它，并按「重跑上限」从头再跑这一项。默认再跑 2 次。

约定写在 `GLOSSARY.md` 和 `docs/adr/`。名单来自苍生铸世之前的公开攻略，和实机不一致时改流水线里的文字。

## 运行

先按 [安装与构建说明](docs/installation.md) 准备 PowerShell 7、MXU 2.8.0、MaaFramework 5.14.3 和中文 OCR v4。下载地址与校验值固定在 [依赖清单](docs/dependencies.json)。项目可放在任意有写权限的目录，日志和导出资料均随项目保存。

只有系统 PowerShell 5.1 时，任务启动前会弹出 PowerShell 7 安装指引；安装 7 后与 5.1 并存，无需卸载系统版本。已装 7 正常继续，并支持从标准安装目录定位尚未进入 PATH 的程序。

1. 将 MXU 的 `mxu.exe` 放在本仓库根目录，将 MaaFramework 的 `bin` 全部内容放到 `maafw/`。
2. 将同一套中文 OCR v4 的 `det.onnx`、`rec.onnx`、`keys.txt` 放进 `resource/model/ocr/`。执行 `pwsh -File tools/build.ps1`，关闭 BJX 后将 `build/tools/` 中的两个 EXE 复制到 `tools/`。
3. 启动 `mxu.exe`。它读取同目录的 `interface.json`。首次安装 PowerShell 或调整 PATH 后重新打开 BJX。
4. 游戏使用窗口模式、1920×1080、界面缩放 100%，先登录，再在界面里选中标题含「剑网3」的窗口。
5. 手动切换至旗舰心法，只勾选「单人吃鸡刷币」。需要定时时，将「定时开始」放在列表最前面并勾选；其余标注「未完成」的任务保持不勾选。吃鸡截止时间默认为任务启动日期的次日凌晨 01:30。

`mxu.exe` 和 `maafw/` 不进 git。OCR 模型在真正做文字识别时再放进 `resource/model/`，默认模型来自 [MaaCommonAssets](https://github.com/MaaXYZ/MaaCommonAssets)。

截图是黑的时，把 `interface.json` 里的 `screencap` 改成 `DXGI_DesktopDup_Window` 或 `ScreenDC`，窗口保持在前台。键鼠没反应时，保持 `Seize`，并让游戏窗口处于前台。窗口类名保持 `KGWin32App`，不要改回 `.*`。这两种都是 MaaFramework 文档里的正式控制方式。

### 网易 UU 远程的鼠标无法切出

如果鼠标能在远程桌面内移动，但到屏幕边缘无法切回操控端，先在**操控端（手边的另一台电脑）**键盘按一次 **Ctrl+Alt+Enter**，退出 UU 的游戏／沉浸式鼠标模式。此快捷键需由操控端处理，在被控电脑上模拟发送不能代替它。运行 BJX 时使用 UU 的普通鼠标模式。

2026-11-04 实机排查时，BJX 全部退出后仍无法切出；被控端光标范围正常，也没有卡住的修饰键，操控端按上述快捷键后恢复。这次现象确认是 UU 一侧保留了鼠标捕获状态，不能用「停止任务」是否返回判断 UU 是否已经退出该模式。触发 UU 切换模式的具体条件尚未确定。

BJX 默认 `Seize` 会激活游戏窗口，点击时移动真实鼠标。窗口消息输入只做过初步兼容验证，Ctrl+L、Shift+C、点击和完整任务尚未全部验收，默认控制方式保留。MXU 的开始／停止快捷键以设置页为准；本机当前是 F10 开始、F11 停止。上文的命令行 F10 停止不代表 MXU 的停止键，也不能解除 UU 的鼠标捕获。

## 本地账号表

打开仓库根目录的 `accounts.csv` 填写资料；新拉取仓库时，将空白模板 [accounts.example.csv](accounts.example.csv) 复制为 `accounts.csv`，保留已有资料。

| 列 | 填写内容 |
| --- | --- |
| 账号 | 登录用的账号，按原样填写并保留前导零 |
| 密码 | 登录密码，按原样填写 |
| 区服 | 游戏选服页显示的完整区服名称 |
| 角色名称 | 角色选择界面显示的完整名称 |
| 备注 | 可留空，例如账号用途 |

一行对应一个角色，同一账号多个角色就填写多行，重复对应账号、密码和区服。文件采用带 BOM 的 UTF-8 编码；用 Excel 导入时将所有列设为文本，避免账号、密码被转成数字或公式，保存时选 CSV UTF-8。

`accounts.csv` 中的资料为明文，只留在本机，已加入 Git 忽略；仓库仅保留空白模板。这次先建立资料表，当前 BJX 尚未从表中读取资料自动登录，账号名和角色名仍在对应任务里填写。

## 范围

助手从已经登录的窗口开始接手。账号资料可填写在本地 CSV 中；当前任务不读取密码，也不处理登录验证。

只做窗口画面和模拟输入。内存读取、注入、改封包不在这个项目里。

自动化操作违反剑网3的使用协议，账号仍可能受到限制。
