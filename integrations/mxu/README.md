# BJX 的 MXU 定制补丁

本目录固定上游 MXU 2.8.0 的提交，并保存 BJX 的 GitHub Releases 更新及启动预任务补丁。`build.json` 记录上游、补丁校验值和定制运行时版本；`github-update.patch` 包含对应源码与测试。

补丁提供公开 GitHub 更新检查、0.x 内测版本比较、精确 Windows x64 整包匹配、下载和安装前 SHA-256 校验，以及安装与任务启动互斥。无 RID 时不显示 CDK 输入，默认内测频道；稳定频道只接收正式发布。用户数据不随整包覆盖。

`2.8.0-bjx.2` 增加连接窗口前的启动预任务保护：任何预任务非零退出或启动失败都会中止本次运行；点击停止会终止启动助手本身，不结束它已打开的游戏。仅勾选预任务时，完成后直接成功返回，不连接窗口、不加载资源。预任务后继续执行普通任务时重新发现并连接窗口；旧标题变化仅在新窗口唯一时自动匹配，多个候选时停止。预任务等待期间与更新安装互斥，参数值不写入日志。

启动预任务按 `interface.json` 中的声明顺序执行，始终早于普通任务（包括普通「定时开始」），不受卡片排序影响。密码应由 Agent 在内存读取本机账号表，不应作为预任务命令行参数传递。

在 Windows x64 安装 Node.js 22、pnpm 10.28.0、Rust stable 和 Visual Studio C++ 构建工具后，在 BJX 根目录运行 `./tools/build-mxu.ps1`。构建使用上游锁文件；失败不会生成可供整包使用的构建回执。发布工作流负责执行前端、Rust、运行门禁和整包检查。

MXU 及本补丁按 AGPL-3.0 分发，许可见 `licenses/MXU-AGPL-3.0.txt`。每次 Release 附带与 `build.json` 版本一致的 `MXU-source-v<runtime_version>.zip` 及 SHA-256，包含完整对应源码、锁文件和测试；BJX 源码包提供本补丁与构建脚本。BJX 自有资源的 MIT 许可不改变第三方代码许可。

这里的补丁是 BJX 自行维护的改动，不代表 MXU 上游已经接受这些修改。升级上游版本时必须重新审查并执行测试。
